# Tutorial para retomar un proyecto en UMLForge AI

Este recorrido práctico enseña a entrar, abrir un proyecto, editar un diagrama, colaborar y recuperar el contexto en otra sesión. Usa únicamente controles disponibles en la versión actual.

## Objetivo del recorrido

Al terminar podrás abrir un proyecto autorizado, guardar una modificación UML, consultar la actividad y regresar después sin perder el diagrama ni la conversación.

## Paso 1 Inicia sesión

1. Abre `/login`.
2. Escribe tu correo y contraseña.
3. Pulsa **Iniciar sesión**.

Si todavía no tienes cuenta, usa **Regístrate**. La recuperación automática de contraseña no está implementada.

## Paso 2 Abre o crea un proyecto

1. En la navegación abre **Proyectos**.
2. Pulsa **Abrir proyecto** sobre uno en el que seas miembro.
3. Si eres Anfitrión o tienes permiso, puedes usar **Nuevo proyecto** y **Guardar**.

Antes de seguir, verifica el nombre del proyecto. Diagramas, chat, participantes e historial deben pertenecer a ese mismo proyecto.

## Paso 3 Invita a un colaborador

Este paso requiere autorización de anfitrión o administrador.

1. Abre **Equipo del proyecto**.
2. Pulsa **Invitar persona**.
3. Escribe el correo registrado.
4. Revisa el perfil **Colaborador del proyecto**.
5. Pulsa **Enviar invitación**.

## Paso 4 Crea o abre un diagrama

1. Vuelve a **Diagramas UML**.
2. Abre un diagrama existente o pulsa **Nuevo diagrama**.
3. En móvil, usa **Ver diagrama UML** para inspeccionar con seguridad.

## Paso 5 Modela una clase y una relación

1. Activa **Modo Edición**.
2. Selecciona **Clase** y toca el lienzo dos veces para crear dos clases.
3. Selecciona cada clase y edita nombre, atributos y métodos en **Inspector**.
4. Selecciona **Asociación** u otro tipo disponible.
5. Marca origen y destino.
6. En Inspector, define **Mult. Origen** y **Mult. Destino**.
7. Arrastra las clases para organizarlas y usa **Centrar vista** si pierdes el encuadre.

## Paso 6 Guarda la versión

Pulsa **Guardar** y espera que termine el estado **Guardando**. La versión confirmada es la que el proyecto recuperará en la próxima sesión.

## Paso 7 Colabora y solicita una revisión

1. Abre **Chat**.
2. Escribe un mensaje al equipo o solicita una revisión UML del diagrama.
3. Lee las recomendaciones estructuradas.
4. Aplica o descarta cada una; confirma explícitamente una eliminación.

No uses el agente de ayuda para modificar el modelo. La ayuda solo explica el procedimiento.

## Paso 8 Consulta la actividad

1. Regresa al proyecto.
2. Abre **Historial y actividad**.
3. Filtra por diagrama, participante o fecha si es necesario.
4. Comprueba que el guardado, la conversación o la decisión aparezcan como eventos reales.

## Paso 9 Cierra y retoma después

1. Cierra sesión o el navegador.
2. Vuelve a iniciar sesión.
3. Abre el mismo proyecto.
4. Revisa **Continuar donde lo dejamos**.
5. Pulsa **Abrir último diagrama** y comprueba el modelo guardado.
6. Abre Chat para recuperar la conversación y **Ver historial** para el contexto completo.

## Paso 10 Intercambia el modelo si lo necesitas

- Para importar: **Herramientas y opciones → Importar XMI → Analizar XMI → Importar al diagrama → Guardar**.
- Para exportar: **Herramientas y opciones → Exportar XMI → Descargar XMI**.
- Para backend: **Herramientas y opciones → Generar Backend Spring → Generar ZIP**.

## Paso 11 Activa notificaciones en un dispositivo

1. Usa HTTPS o `localhost`.
2. Abre **Notificaciones**.
3. Pulsa **Activar notificaciones** y concede el permiso.
4. Selecciona preferencias y pulsa **Enviar prueba**.

## Comprobación final

El recorrido es correcto si el mismo proyecto conserva el diagrama guardado, Chat recupera mensajes anteriores, Historial muestra eventos persistidos y la tarjeta de continuidad resume el trabajo sin ejecutar IA automáticamente.
